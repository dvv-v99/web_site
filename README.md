# Dudin Business Card Site

Текущий этап: Проект закончен ! (Неделя 10)


### Текущие фичи:

1. Меню с вкладками "Главная", "Проекты", "О нас", "Контакты"

2. Футер с названием проекта и текущим годом

3. На "Главная": Приветственная надпись, карусель, карточки последних проектов, отзывы

4. В разделе "Проекты": Карточки проектов

5. В разделе "О нас": Карточки сотрудников

6. В разделе "Контакты": Контактные данные, форма обратной связи

7. Создана admin-панель, все данные можно менять без кода

8. Сайт приведен к единому стилю


#### Запуск проекта

1.Установить Python (3.12+)

2.Установить Django

3.Перейти в корень проекта

4.Прописать в терминале
``` 
python manage.py runserver
```
